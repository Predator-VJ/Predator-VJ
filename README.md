## <img src="https://media.giphy.com/media/3oKIPnAiaMCws8nOsE/giphy.gif" width="36"/> &nbsp; Signature Wins

- **Datacenter consolidations** &mdash; led multi-cluster VMware migrations with zero unplanned downtime, retiring legacy hardware fleets.
- **PowerShell at scale** &mdash; authored automation libraries that reduced repetitive sysadmin work by an order of magnitude.
- **Citrix CVAD platforms** &mdash; designed and operated published-app and VDI environments serving thousands of concurrent users.
- **Identity hardening** &mdash; tightened Active Directory hygiene, Tier-0 boundaries, and privileged-access workflows across the estate.
- **Mentorship** &mdash; coached junior admins into senior engineers; the best automation I ever wrote was other people.
